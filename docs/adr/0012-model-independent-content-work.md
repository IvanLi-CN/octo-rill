# ADR 0012: 模型无关的全局内容工作身份

## Status

Accepted

## Context

全局翻译与润色运行时目前把模型档案纳入工作项和结果投影身份，并在工作项上冻结配置指纹。相同规范资源和源版本因此可能因模型路由变化形成不同身份；已发布的有效内容也可能被当前模型配置遮蔽。执行前配置变化还会把工作置为 `blocked_config`，但配置阻塞不等同于源内容永久失败。

模型路由是一次执行使用的配置事实，不是 Release、公告或通知内容的身份。工作项应跨配置变更保持稳定，同时仍须审计每次尝试实际采用的路由和配置。

## Decision

- 全局工作身份为 `(canonical_resource_type, canonical_resource_id, pipeline, variant, target_lang, source_hash, protocol_version)`；模型档案、路由和配置指纹不参与工作去重。
- 当前结果投影身份为 `(canonical_resource_type, canonical_resource_id, pipeline, variant, target_lang, source_hash, protocol_version)`，与工作身份保留相同的完整源身份。投影记录的源哈希必须与身份中的 `source_hash` 一致；当前结果不按模型分叉。
- 每次尝试开始时记录当时有效的全局配置与有序路由快照。快照在该次尝试内固定；后续尝试采用开始时的当前配置。保存安全配置字段和非可逆凭据指纹，不保存密钥原文；每个 provider 调用关联实际模型。
- 当前配置无效时，工作进入可恢复的 `blocked_config`，不调用 provider，也不按计时器重试。相关配置更新或运行时配置重载触发重新验证；验证有效后由调度器自动重新排队。配置变更不重跑已有有效结果；没有对同源内容的强制重生成入口。
- 升级时，按模型无关身份归并既有工作和投影，并保留尝试、调用、请求关联及输出证据。多个模型专属有效投影中，最近发布的有效投影作为唯一当前结果。既有 `blocked_config` 仅在没有匹配源哈希的有效当前投影时自动排队恢复；若已有匹配投影则保留结果而不调用模型。恢复遵循正常调度、并发和 provider 防护。

## Considered Options

- 将模型档案继续保留在工作和结果身份中：拒绝。模型配置是执行选择，不应把同一内容拆成多个全局记录，也不应让配置变化隐藏已有有效输出。
- 配置变化时重跑全部已完成结果：拒绝。配置变化本身不代表源内容变更或当前输出无效，且会造成不必要的模型调用。
- 将所有 `blocked_config` 工作无条件立即重跑：拒绝。已有匹配源版本的有效投影无需再生成；恢复仅覆盖没有有效结果的内容身份。

## Consequences

- 同一内容身份跨模型配置保持稳定；新尝试可采用更新后的配置，运行中的尝试保持原配置快照。
- 管理与审计通过尝试和调用关联查看实际模型及配置，而不是从工作项身份推断。
- 配置阻塞可在修复后自动恢复，但没有周期性无效调用；有效结果不会因模型设置改变而失效或自动重跑。
- 模型专属历史记录必须安全归并，保留审计关联，并只公开一个当前有效投影。
- 旧工作级配置指纹保留为历史事实，不得伪造为旧尝试的配置快照。
- 身份升级先发布只添加结构的兼容版本，再发布不增加新迁移的身份切换版本；兼容版本是切换后的回退下界，迁移前二进制不支持打开新 schema。
