# Web Demo

`/demo/` 是 OctoRill 的页面级 `mock-only` 子应用：它复用真实页面组件和真实 route suffix，但通过 `?demo=` 与 `d_*` 分享态进入 demo runtime，不依赖真实登录、真实 `/api/**` 或真实后端写路径。

默认 demo scene 中出现的 owner / repo、邮箱、PAT mask 与 API key 只使用合成样例，例如 `octo-demo/release-lab` 与 `*.octo.demo`；它们不会映射到真实私有仓库或真实凭据。即使你在 demo 里手动输入 PAT，保存后的 UI 也只会回显固定假 mask，不会截取你的 secret 前缀。

## 它负责什么

- 页面 / 流程级视觉证据
- owner-facing 验收 deep link
- mock-only 数据回放、persona 切换与 simulated writes

## 它不负责什么

- 组件级 docs / autodocs / interaction coverage
- 替代 Storybook 的局部状态 QA
- 连接真实 GitHub OAuth、真实 SQLite 或 production 写路径

## 分享态合同

- `demo=<scene-id>`：当前 scene
- `d_persona=`：`guest | member | admin`
- `d_net=`：`normal | slow | faulty`
- `d_own=1`：打开“我的发布”
- `d_pub=published`：演示 repo public release 已发布

面板位置只存本地；scene、persona、network 和关键 toggle 会写进 URL，方便复现同一条验收链接。

## Inspector 行为

- 桌面端：可拖拽、吸边、收起成气泡
- 移动端：`bubble -> drawer`
- 所有写操作：只更新 demo 内存态，并显式标记为 simulated

## 和 Storybook 的边界

- Storybook：组件、抽离 fragment、docs/autodocs、`play` 覆盖
- Web Demo：完整页面、跨区域状态组合、页面级最终视觉证据
