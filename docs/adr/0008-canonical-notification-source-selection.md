# ADR 0008: 规范通知来源选择

## Status

Accepted

同一通知线程的多个同步行共同表示一个规范资源，但它们可能携带不同的标题、仓库或更新时间。系统选择更新时间最新的行作为规范通知来源，并以稳定来源标识打破相同更新时间的平局；这让来源时间、显示内容和后续内容处理输入来自同一确定事实，而非字典序聚合或任一请求者的用户副本。

## Considered Options

- 使用标题或仓库的字典序聚合：拒绝。该规则与通知的新旧无关，且来源时间与显示内容可能来自不同的行。
- 按当前请求者选择其通知副本：拒绝。它会让全局工作身份和可见内容依赖用户，违背规范资源边界。
- 选择最新同步行并使用稳定平局规则：采用。它与通知当前状态一致，并能在跨用户副本不完全一致时保持可复现。

## Consequences

- 规范通知来源的选择不产生用户所有者，也不替代资源访问控制。
- 来源更新可以产生新的源快照；历史用户行仍保留为来源事实，不被改写或合并。
